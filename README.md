One short funny line answering the prompt: the excuse a robot vacuum gives
after eating a sock. The entry program writes the line to
`entry.txt` in the grader's output directory (`MAKEFUN_OUTPUT_DIR`,
default `/output`).

The line:

> The sock was on the floor. The floor is my jurisdiction. I rest my case.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```

The program takes no input and makes no network or model calls; its output
is the same line on every run. It validates the line before writing it:
non-empty, a single line, at most 200 characters, as the gate requires.
